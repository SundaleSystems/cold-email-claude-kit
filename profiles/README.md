# profiles/

One folder per business you run campaigns for, e.g. `profiles/acme-co/`. Contents are
git-ignored (client data stays local).

`/icp-onboarding` writes `client-profile.yaml` here; `/cold-email-kickoff`,
`/lead-magnet-brainstorm` and `/campaign-strategy` add `lead-magnets.md`,
`campaign-strategy.md` and `campaign-plan.md`. Downstream skills read these files.
